Organizar reúne en la app todo lo que hacen el CEE y la administración: notificaciones, eventos, entradas, avisos, votaciones, los Presidentes de curso y el aniversario.

**Quién lo usa:** el CEE y la administración. Se abre con el botón **Organizar**, junto al buscador del Inicio. Cuando tienes un evento con la puerta abierta, el botón lleva un punto rosado.

## Qué hay dentro

| Sección | Qué haces |
| --- | --- |
| **Hoy** | Los eventos del día con el conteo de llegadas en vivo y el botón para escanear. |
| **Notificaciones** | Un mensaje corto que llega al instante al teléfono de quienes elijas. |
| **Publicar** | Un aviso, una votación o un evento. |
| **Eventos y entradas** | Todos tus eventos, filtrados por tipo, con inscritos, entradas emitidas y llegadas. |
| **Cursos y clases** | Nombrar Presidentes de curso. La administración también suspende clases o adelanta la salida. |
| **Aniversario** | Las herramientas del aniversario, si el módulo está activo. |

## Notificaciones

Para lo que no puede esperar: un cambio de sala, un recordatorio, una citación. Llega como notificación y queda guardado en la sección [Notificaciones](../notificaciones/) de cada persona.

1. En Organizar, abre **Notificaciones** y escribe el mensaje (hasta 200 caracteres).
2. Elige a quién le llega:

| Destinatarios | Administración | CEE |
| --- | :-: | :-: |
| Todo el liceo o una jornada (con opción de sumar docentes y administración) | ✓ | ✓ |
| Algunos cursos | ✓ | ✓ |
| Los Presidentes de curso o las Directivas | ✓ | ✓ |
| Un grupo guardado ("Grupos de estudiantes") | ✓ | |
| Estudiantes elegidos uno por uno | ✓ | |

3. Si quieres, haz que al tocarla abra el Calendar o un evento del liceo.
4. Revisa cómo quedará y confirma **"¿Enviar a N personas?"**.

- Sale a nombre del Espacio (la Comunidad del liceo o el CEE), no de una persona.
- **Una notificación enviada no se borra.** Revísala antes de confirmar.
- Una jornada incluye también a quienes todavía no eligen la suya.
- Cada liceo puede enviar hasta **5 al día desde el CEE** y **30 al día desde la administración**.
- **Enviadas** muestra el historial. La administración ve quién envió cada una; el CEE ve las suyas.

## Publicar

- **Un aviso:** se publica en el Feed, en el Espacio que te corresponde (la Comunidad del liceo para la administración, el Espacio del CEE para el CEE). Ver [Feed](../feed/).
- **Una votación:** abre el formulario con la votación lista. Siempre anónima.
- **Un evento:** elige el tipo:

| Tipo | Para qué |
| --- | --- |
| **De la institución** | En Eventos, para todo el liceo o una jornada, con o sin inscripción. Ver [Eventos del liceo](../eventos/). |
| **Privado o formal** | Una gala o una velada: solo lo ven quienes tienen entrada. Ver [Entradas](../entradas/). |

## El día del evento

Desde 3 horas antes y hasta 24 horas después del evento, el Inicio muestra **"Hoy organizas"** con cuántos llegaron y el botón **Escanear**. Según el evento, abre el escáner de entradas o Pasar lista con HN-QR.

HaNet es una **base** que todo liceo tiene, más **módulos** que tu liceo activa solo si los necesita. Un módulo apagado no queda escondido en la app: el servidor deja de responderle.

## La base

Viene con todo liceo, siempre.

| Sección | Para qué sirve |
| --- | --- |
| [Calendar](calendar/) | La agenda de cada curso: evaluaciones, tareas y actividades, día a día. |
| [Horario](horario/) | El horario de cada curso, con recreos, electivos y el resumen de las 7:00. |
| [Días sin clases](dias-sin-clases/) | Suspensiones y salidas anticipadas, que se reflejan solas en el Calendar. |
| [ClassHall](classhall/) | Las clases: anuncios, material, evaluaciones con su tabla de especificaciones y tareas con entregas. |
| [Eventos del liceo](eventos/) | Actividades del liceo con inscripción y asistencia con HN-QR. |
| [Organizar](organizar/) | Las herramientas del CEE y la administración en un solo lugar. |
| [Notificaciones](notificaciones/) | Todo lo que HaNet avisa, guardado al final del Inicio. |
| [Herramientas](herramientas/) | Escala de notas, calculadora de notas y verbos en inglés. |

## Módulos que se activan

| Módulo | Para qué sirve |
| --- | --- |
| [Notas](notas/) | Las notas de cada evaluación, que el estudiante destapa en pantalla completa. |
| [Entradas](entradas/) | Entradas con QR para galas, veladas y eventos con cupo, revisadas en la puerta. |
| [Feed](feed/) | Comunicados del liceo, del CEE y de cada curso, con reacciones. |
| [Votaciones](feed/#votaciones) | Votaciones siempre anónimas dentro del Feed. Necesita el Feed. |
| [Aniversario](aniversario/) | Alianzas, marcador en vivo, actividades, puntos y pruebas flash. |
| [HaNet Electividad](herramientas/#hanet-electividad) | Test de intereses para elegir electivos en 2° medio. |

Además, [Cerca de mí](eventos/#cerca-de-mí) muestra panoramas de la ciudad que carga el equipo de HaNet.

## Cómo activar o apagar un módulo

Pídelo al equipo de HaNet en [muxp@muxp.art](mailto:muxp@muxp.art). El cambio se aplica de inmediato para todo el liceo. Al apagar un módulo, lo que ya existía se conserva y vuelve a verse si se activa otra vez.

## Después de la beta

- **Notebook:** asistencia, faltas y el libro de clases completo, como reemplazo del libro actual del liceo.
- **Wallet:** las finanzas de cada curso.
